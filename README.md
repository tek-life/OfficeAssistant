# 办公助手 (OfficeAssistant)

一款常驻系统托盘的 Windows 桌面小工具，把**今日待办**以便签风格渲染到桌面壁纸上，并集成了**工作日志**与**番茄钟**休息提醒。所有数据保存在本地 SQLite 数据库中。

## 功能特性

- **待办便签壁纸**：把当天的 TODO 列表以便签风格绘制到桌面壁纸的角落，条目数量不限，随内容自动调整高度。
- **今日待办管理**：托盘菜单打开待办编辑窗口，支持添加、勾选完成、删除。
- **工作日志**：每天一篇 Markdown 日志。默认阅读模式（渲染后的 Markdown），点击「编辑」按钮或双击正文即可进入编辑模式，带格式工具栏，可浏览历史日志。
- **一键投递**：桌面常驻一个「投递气泡」，左键即把当前选中的文字追加到当天日志，右键弹出菜单选择投递剪贴板或打开日志；也支持全局热键与托盘入口，条目自动带上时间和来源窗口。
- **阅读疑难**：在网页上选中读不懂的句子，用配套的 Chrome 扩展一键标记；所有疑问汇总到桌面的「疑难气泡」和清单窗口，每条都能跳回原文并高亮，读完后可逐条标记已解决。
- **番茄钟**：默认工作 60 分钟后提醒休息 5 分钟。休息前弹出选择框（休息 / 再工作 5 分钟 / 跳过），休息时显示全屏倒计时，可随时跳过开始下一轮。便签上会实时显示工作/休息倒计时。
- **单实例运行**：重复启动会通知已运行的实例刷新壁纸并自动退出。
- **壁纸备份与还原**：首次运行备份原始壁纸，随时可从托盘菜单一键还原。

## 环境要求

- Windows 10 / 11
- Python 3.12+（开发验证于 3.14）

## 安装与运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 直接运行
python src/sticky_wallpaper.py
```

程序启动后不会显示主窗口，而是常驻系统托盘。右键托盘图标即可使用各项功能。

## 打包为独立 exe

推荐使用已提交的 PyInstaller 配置文件打包（已排除无用的 Qt 模块以减小体积）：

```bash
pyinstaller OfficeAssistant.spec --noconfirm
# 产物：dist\OfficeAssistant.exe
```

也可以直接双击运行 `build.bat`，它会自动检查环境、停止旧进程并调用上述 spec 完成打包。

> 重新打包前需先关闭正在运行的 `OfficeAssistant.exe`，否则 PyInstaller 会因文件占用报 `PermissionError`。

## 运行测试

```bash
py -3 test/_run_tests.py            # 运行 test/ 下的全部用例
py -3 test/_run_tests.py test_db    # 只运行指定模块
```

测试运行器会先把 `src/` 与 `test/` 加入 `sys.path`（源码模块之间用裸名互相 import），临时目录落在仓库根目录的 `.runtmp/` 下。


## 使用说明

右键系统托盘图标，可进行以下操作：

- **刷新壁纸**：立即重新渲染便签壁纸（默认每 5 分钟自动刷新一次）。
- **编辑待办**：打开待办管理窗口。
- **工作日志**：打开当天日志，默认阅读模式，双击正文或点「编辑」进入编辑。
- **记录选中内容 (Ctrl+Alt+N)**：把当前前台窗口里选中的文字追加到当天日志。
- **记录剪贴板 (Ctrl+Alt+Shift+N)**：把剪贴板里的文字追加到当天日志。
- **投递气泡**：勾选/取消桌面上的投递气泡（见下）。
- **阅读疑难**：打开阅读疑难清单窗口。
- **疑难气泡**：勾选/取消桌面上的阅读疑难气泡（见下）。
- **番茄钟休息提醒**：勾选开启/关闭番茄钟。
- **还原壁纸**：把壁纸还原为程序运行前的原始壁纸。
- **退出**：还原壁纸并退出程序。

投递的条目会追加在当天日志末尾，形如 `- 09:12 [Chrome - 某页面] 摘录内容`；多行内容里除首行外都会变成缩进的子项。没有选中内容时不会改动剪贴板，日志窗口正开着当天日志的话会立刻看到新条目。

桌面上默认常驻一个**投递气泡**，是比热键更直观的入口：左键单击即记录当前选中的文字，右键弹出菜单（记录选中内容 / 记录剪贴板 / 打开工作日志 / 隐藏气泡）。气泡可以拖到任意位置，位置会被记住；点击它不会抢走前台焦点，因此不影响你正在操作的窗口。投递结果直接显示在气泡上（例如 `已记入 10-19`），不用去翻托盘通知。不想看到它时，在托盘菜单里取消勾选「投递气泡」即可。

桌面上另有一个与投递气泡相互独立的**疑难气泡**，用来收纳阅读时遇到、想回头再琢磨的疑问：左键打开阅读疑难清单，右键弹出菜单（打开疑难清单 / 隐藏气泡）。清单里「待解决」与「已解决」分两个标签页，点每条右侧或底部的「打开原文」会回到浏览器并高亮当时的句子，读懂了就点「标记已解决」归档。疑问来自配套的 Chrome 扩展（`chrome_extension/`）：在网页上选中句子，右键「标记疑难」，即可把它连同原文锚点投递到本程序。

扩展安装方式：打开 Chrome 的 `chrome://extensions`，开启右上角「开发者模式」，点「加载已解压的扩展程序」选择本项目的 `chrome_extension` 目录即可。标记时需要本程序正在运行（本地接收服务监听 `127.0.0.1`，默认端口 `8765`）。

## 项目结构

| 路径 | 说明 |
|------|------|
| `src/` | 源码目录（模块之间用裸名互相 import，运行或打包时需把 `src/` 加入 `sys.path`） |
| `src/sticky_wallpaper.py` | 主程序：便签渲染、壁纸管理、系统托盘、番茄钟、单实例控制 |
| `src/db.py` | SQLite 存储层：待办、工作日志、应用设置三张表，含从旧版 `todos.txt`/`config.json` 的自动迁移 |
| `src/qt_gui.py` | 基于 PySide6 (Qt) 的 GUI 模块：工作日志窗口、待办编辑窗口、桌面投递气泡、疑难清单 |
| `src/capture.py` | 内容投递：读取选中内容 / 剪贴板，生成带时间与来源的条目并追加到当天日志 |
| `src/question_server.py` | 阅读疑难的本地接收服务：接收扩展投递的 JSON，生成回跳链接，写入数据库 |
| `src/window_chrome.py` | 无边框窗口的自绘标题栏与缩放边缘 |
| `test/` | 测试目录（`test_*.py` 用例与 `_run_tests.py` 运行器） |
| `db/` | 运行时数据目录，存放 SQLite 数据库 `sticky_wallpaper.db` |
| `config/` | 配置目录；仅作旧版 `config.json` 的迁移来源，设置实际存在数据库的 `app_settings` 表 |
| `dist/` | 构建产物目录，存放 `OfficeAssistant.exe` |
| `chrome_extension/` | Chrome MV3 扩展：把网页上标记的句子与锚点投递到本程序，并负责回跳高亮 |
| `OfficeAssistant.spec` | PyInstaller 打包配置 |
| `build.bat` | 一键打包脚本 |
| `requirements.txt` | Python 依赖清单 |

## 数据存储

所有数据保存在程序目录下的 `db/sticky_wallpaper.db`（SQLite）中，包含四张表：

- `todos`：待办事项
- `daily_notes`：工作日志（每天一条，Markdown）
- `app_settings`：应用设置（key-value）
- `questions`：阅读疑难（网页摘录、原文锚点与已解决状态）

首次运行时，如检测到旧版的 `todos.txt` 或 `config/config.json`，会自动导入数据库并把原文件重命名为 `.bak` 备份。

## 技术说明

GUI 采用 PySide6 (Qt) 而非 tkinter。原因是 Windows 上 tkinter 的 TSF 输入法支持不完整，导致中文拼音组词串字号不跟随正文字体（偏小）；Qt 的 `QTextEdit` / `QLineEdit` 有完整 TSF 支持，拼音串会自动与正文等大。Qt 事件循环运行在独立线程，所有窗口操作通过请求队列投递到该线程执行，以满足 Qt「控件只能在其创建线程操作」的约束。

一键投递用 `RegisterHotKey` 注册全局热键，注册与 `GetMessageW` 消息循环跑在同一个专用线程里（Win32 的硬性要求），收到热键后由后台线程抓取内容、写入数据库，再通过 Qt 线程队列把新条目同步进已经打开的日志窗口。

桌面投递气泡（`CaptureBubble`）同样是 Qt 控件，运行在 Qt 线程里。它用 `WS_EX_NOACTIVATE` / `WS_EX_TOOLWINDOW`（以及 `WindowDoesNotAcceptFocus`）保证点击气泡时不抢前台焦点，这样「记录选中内容」注入的 `Ctrl+C` 才能命中你原来正在操作的窗口。
