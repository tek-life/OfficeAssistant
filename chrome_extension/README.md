# 办公助手 · 阅读疑难（Chrome 扩展）

阅读网页时把不懂的地方标记下来，全部汇总到桌面端「办公助手」的**阅读疑难**清单，
之后回到清单逐条攻克；每条都能一键跳回原文并高亮当时的句子。

## 组成

- `content.js`：在页面上采集选中文字的锚点（原文 + 前后文 + 字符偏移），
  并在通过 `#oaq=` 片段打开页面时定位、滚动并高亮该句。
- `background.js`：右键菜单「标记疑难」把选中内容 POST 到本机服务；
  同时转发弹出面板的投递请求。
- `popup.html` / `popup.js`：点扩展图标可补一句问题、选分类与优先级再投递。

## 安装

1. 打开 Chrome → `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录

## 使用

- 在网页上选中不懂的句子 → 右键「标记疑难」→ 立即记录（可稍后在清单里补充问题）。
- 或点扩展图标 → 填写问题/分类/优先级 → 「标记疑难」。
- 桌面端「办公助手」会收到提示，疑难气泡上的计数 +1；点气泡或托盘「阅读疑难」查看清单。

## 依赖

- 桌面端「办公助手」需要在运行（默认监听 `http://127.0.0.1:8765/`）。
- 端口可用数据库 `app_settings` 表（旧版为 `config/config.json`）里的 `question_server_port` 修改，
  改端口后请同步修改 `background.js` 顶部的 `ENDPOINT` / `HEALTH`。
